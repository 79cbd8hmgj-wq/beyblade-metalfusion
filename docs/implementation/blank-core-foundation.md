# Blank Core foundation

## Implemented

The Blank Core is modeled as a dormant virtual identity overlay in custom state. The model sanitizes the Blank Core ID back to `0xF0` and state back to dormant.

## Candidate

The preferred future implementation is an identity overlay that keeps retail battle code on a valid neutral Bit Chip while overriding player-facing identity and suppressing Bit Beast/Special Move presentation.

## Unknown / unexecuted

No Bit Chip consumer hook is installed, and `0xF0` is not fed into retail arrays.
