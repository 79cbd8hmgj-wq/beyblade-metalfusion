# Rejected and bounded hypotheses

* **`0x000796DC` is the master table — rejected (confirmed counterevidence).** It is concatenated pointer lookup data with repeated 5/10-column strings and no configuration payload. The accessor instead adds `0x0807A1F4`.
* **Ten identical pointers mean five languages times two contexts — rejected for the complete table.** The actual records use five language pointers followed by non-name payload. Ten-pointer runs occur in the preceding mixed category lookup and reflect adjacent category rows/duplication; column semantics there remain unknown.
* **String order supplies canonical IDs — rejected.** Strings are laid out in reverse table order. IDs come only from the code-indexed record rows.
* **The table is a pointer array — rejected.** Consecutive returned addresses differ by 40 and the accessor performs fixed-stride arithmetic.
* **The records are self-contained runtime objects — rejected as phrased.** Two ROM pointers and packed IDs imply a template expanded/cross-referenced elsewhere; RAM battle structures are separate.
